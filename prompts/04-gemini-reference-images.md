# 04 — Gemini reference images (the consistency anchor)

> Gemini 2.5 Flash Image ("Nano Banana") keeps the recurring character on-model by **conditioning on
> reference images** you pass in alongside the prompt — not by a fixed seed. Bootstrap these **once**,
> commit them to `assets/refs/`, and every character shot reuses them. Generated by `tools/make_refs.py`.

## The reference set
| Ref | File | What it is | Passed on… |
|---|---|---|---|
| **REF-1 — character model sheet** ⭐ | `assets/refs/character.png` | The recurring stick-figure, neutral standing pose, plain background — the **identity anchor**. | every `character` / `wide` shot |
| **REF-2 — expression sheet** | `assets/refs/expressions.png` | The *same* head ×6: calm, worried, sad, surprised, angry, thoughtful. | emotional character shots |

`concept` / `map` shots pass **no refs** (don't force a person into a prop or a map).

## How they're created (bootstrap, once)
1. **REF-1** = text→image (no reference):
   ```
   A character model sheet for one recurring crude white-headed stick person on a plain pale background, matching a low-budget hand-drawn educational web-cartoon frame. Thick uneven black marker outlines, wobbly imperfect linework, flat fill colors only, no shading, no gradients. The character has a circular white face, tiny black dot eyes, one small black line mouth, no nose, thin black noodle arms and legs, tiny line hands and feet, wearing a simple flat tunic. Show clothing only as crude flat add-ons on the stick body, never as realistic anatomy or detailed costume. Front view, neutral standing pose, full body, lots of empty space, no text. Avoid: photorealistic, 3D, Pixar, Disney, anime, vector illustration, cinematic lighting, polished corporate illustration, ornate clothing, detailed face, busy background.
   ```
   Generate, pick the cleanest → that image is REF-1 forever.
2. **REF-2** = REF-1→image edit (condition on REF-1):
   ```
   Using the exact crude white-headed stick person in the reference image, draw the same round white head six times in a simple grid with these marker-cartoon expressions: happy, worried, sad, surprised, angry, neutral. Keep the identical thick uneven black line weight, dot eyes, tiny line mouth, optional eyebrows, flat colors, and low-budget hand-drawn look. Plain pale background, no text.
   ```
Run both with `python tools/make_refs.py [--beard] [--hair "messy hair"] [--clothes "simple tunic"]` (needs `GEMINI_API_KEY` + billing).

## Per-scene call (the pipeline does this)
final image = **REF-1 (+ REF-2 if emotional)** + the scene prompt from [02](02-image-prompts.md), phrased
as an edit instruction:
> *"Using the crude white-headed stick person in the reference image, show them {action},
> {explicit facial expression}, {props}. Keep the round white head, dot eyes, tiny line mouth,
> noodle limbs, thick uneven marker line weight, flat colors, and low-budget hand-drawn look."*

The face is the only emotion signal — always state the expression. The bases stay byte-for-byte identical.

## Cost
Refs are input → ~$0.0004 each, negligible. The output image is the cost (~$0.039). Passing both refs on
every character shot adds <0.1¢/scene. See [blueprint](../context/project/blueprints/gemini-image-provider.md).
